# ANTI-SANDBOX

**status_authority:** `NONE` forever  
**Parody / inverse of:** [Natoshi-moto/Experimental-Sandbox](https://github.com/Natoshi-moto/Experimental-Sandbox)

## Sandbox in one line

Public fuck-around land with SBX IDs, doors for non-coders, and a **promotion package** toward Lab.

## Anti-Sandbox in one line

Public fuck-around land that assumes your idea is **too filthy for Sandbox** until proven otherwise — and laughs at you for wanting a hall pass early.

## Differences that matter

| Experimental-Sandbox | Anti-Sandbox |
|----------------------|--------------|
| `SBX-*` IDs | `ANTI-SBX-*` only |
| Promotion toward Lab is imaginable | Promotion toward **Sandbox** is the ambitious dream |
| “Let’s fuck around” with house rules | “Let’s fuck around” with **stricter outbound** rules |
| Manners for public science | Manners optional; **isolation not optional** |
| Adjacent assistant / Mithub doors | Optional later; not required for genesis |
