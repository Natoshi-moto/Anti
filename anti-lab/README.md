# ANTI-LAB

**status_authority:** `NONE` forever  
**Parody / inverse of:** [Natoshi-moto/Lab](https://github.com/Natoshi-moto/Lab)

## What Lab is (so we can invert it)

Lab is a public research operating system: constitutions, evidence grades, multi-seat audits, emergency stops, “don’t trust this project,” promotion discipline.

## What Anti-Lab is

Same **shape** (so agents can navigate). Opposite **incentives**:

| Lab incentive | Anti-Lab incentive |
|---------------|--------------------|
| Don’t overclaim | Overclaim *inside Anti*, then murder the claim with tests |
| Multi-seat agreement as caution | Multi-seat disagreement as sport |
| Canon carefully | Anti-canon proudly |
| Emergency stop feature work | Emergency stop **upstream contamination** |
| Reputation-aware | Reputation is Lab’s problem |

## Rules of engagement

1. Everything in Anti-Lab is **radioactive to Lab main**.  
2. You may simulate Lab-like process for practice — mark it `SIMULATED`.  
3. Real Lab process only exists **in Lab**.  
4. If your experiment needs Lab data, copy **public** artifacts only and cite them; don’t reach into private operator state.
