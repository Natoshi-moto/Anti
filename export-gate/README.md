# EXPORT GATE

**status_authority:** `NONE`  
**Attitude:** you are not special; your baby is probably ugly  

This is the **only** sanctioned fantasy in which Anti material moves toward Experimental-Sandbox or (almost never) Lab.

## Default output

**REJECT.**

If you are surprised, reread the charter.

## Flow

1. Author fills `TEMPLATE_EXPORT_PACKAGE.md` → save as `PACKAGE_ANTI-EXP-####_slug.md`  
2. Optional second seat tries to kill it (`REVIEW_*.md`)  
3. Human operator says go / no-go in writing in the package  
4. **Only then** may a human open a PR on the **destination** repo using destination rules  
5. Anti does not auto-open those PRs  

## Destination rules of thumb

| Destination | When even think about it |
|-------------|---------------------------|
| Nowhere | default |
| Stay in Anti | almost everything |
| Experimental-Sandbox | survived mockery + falsifier + no secrets + operator go |
| Lab | after Sandbox manners *and* Lab intake — Anti swagger removed |

## Cocky truth

Export gate exists so Anti can be feral **without** becoming a supply chain attack on Lab.
