# Lab vs Experimental-Sandbox vs Anti

**status_authority:** `NONE`

| Dimension | Lab | Experimental-Sandbox | **Anti** |
|-----------|-----|----------------------|----------|
| Purpose | Canonical research OS | Public experiments with manners | Quarantine for crazy shit |
| Authority | Process-heavy; still self-distrusting | `NONE` but promotion imaginable | `NONE` forever, louder |
| Tone | Serious / scarred | Playful chaos | Cocky dickhead + strict isolation |
| Default output | careful records | SBX experiments | radioactive drafts |
| Upstream | N/A (it *is* upstream) | may request Lab | may request **Sandbox** if lucky |
| IDs | Lab scheme | `SBX-*` | `ANTI-*` only |
| Success | truth-tracking under pressure | learning in public | non-contamination + learning |
| Failure mode | overclaim, gate lies | thinking it’s Lab | leaking upstream |

## One-liner

Lab = monastery.  
Sandbox = makerspace with a waiver.  
Anti = the locked basement where the waiver is “don’t go upstairs.”
